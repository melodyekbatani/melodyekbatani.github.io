# Index

## Introduction
This project was created for Typography & Interaction in the Parsons MPS Communication Design program, taught by Michael Fehrenbach and Eric Li. The assignment was to create a landing page showcasing the 5 key projects we developed over the year-long course. Working on this project, it made it clear the growth and progress I’ve made over the past year in both design and code.  As always, I designed mobile first, building the layout from the smallest breakpoint outwards, while prioritizing space within the viewport .
